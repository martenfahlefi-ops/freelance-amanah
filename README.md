# FREELANCE AMANAH

> Platform Setoran Freelance Management System

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript, EJS
- **Backend**: Node.js, Express.js
- **Database**: SQLite (better-sqlite3)
- **Security**: Helmet, bcrypt, XSS protection, Express Session

## Quick Start
```bash
npm install
npm start
```

## Access
- **Landing Page**: http://localhost:3000

- **Member Page**: http://localhost:3000/member

## Features
- 🔐 Admin panel with password hash (bcrypt)
- 📊 Real-time stats dashboard
- 📝 Member setoran submission
- 📋 Admin confirmation (Pending/Accepted/Denied)
- ⏰ Open/Close schedule system
- 💰 Auto-calculated payment totals
- 🔄 Auto-reset at midnight
- 📧 Email list management
- 📜 Reset history tracking
- 🎨 Premium green + black glassmorphism theme
- 📱 Fully responsive (mobile, tablet, desktop)
- 💬 Floating Discord button
